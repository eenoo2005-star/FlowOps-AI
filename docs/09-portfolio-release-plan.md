# FlowOps AI — Portfolio Release Plan

## Decision

Stop expanding the product scope.

FlowOps AI already contains enough substance for a strong employment portfolio project. The remaining work is presentation, verification, and packaging — not another long feature phase.

## Final Goal

Prepare FlowOps AI for:

- GitHub portfolio
- LinkedIn feature post
- CV project section
- Interview walkthrough
- Remote job applications
- Short demo video

## Final Scope Cut

Do not build these before portfolio release:

- Multi-tenancy polish
- Billing
- AI Assistant
- Advanced reporting builder
- Full API token management
- Real email integration
- Advanced password policy UI
- Complex audit timeline
- Mobile app
- Kubernetes deployment

These can be roadmap items. Building them now will delay the main goal: getting remote work interviews.

## Finish Definition

FlowOps AI is considered portfolio-finished when:

1. The demo flow works end-to-end.
2. The README explains the project clearly.
3. Screenshots/video exist.
4. GitHub is clean.
5. CV and LinkedIn include the project.
6. The project can be explained in 2 minutes.

At that point, development stops and job application execution begins.
