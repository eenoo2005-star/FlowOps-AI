# FlowOps AI — Demo Script

Use this flow when presenting the project to recruiters, managers, or interviewers.

## 1. Opening

FlowOps AI is an enterprise workflow platform for managing internal company requests, approvals, notifications, analytics, and administration.

## 2. Login

Login using the admin account and show the professional dashboard.

## 3. Dashboard

Show:

- Operational cards
- Navigation between modules
- Analytics summary
- Dark/light theme

## 4. Departments and Employees

Create or edit a department and employee to show CRUD operations, validation, loading states, and success toasts.

## 5. Request Types and Workflows

Show how request types connect to workflows.

Explain that a request type must be active and linked to an active workflow before employees can create requests.

## 6. Internal Request Creation

Create a request and show:

- Request type selector
- Requester employee selector
- Clean dropdown behavior
- Ownership/on-behalf-of logic
- Submission success toast

## 7. Approval Inbox

Open the approval inbox and approve/reject a request.

Show how the request status changes.

## 8. Notifications

Show assignment, approval, read/unread, and notification bell behavior.

## 9. Analytics

Show approval rate, pending requests, created requests, average completion, department statistics, SLA statistics, and approval performance.

## 10. Administration

Show:

- Roles
- Permissions
- Audit logs
- Settings area

## 11. Technical Summary

Mention:

- Laravel API
- PostgreSQL
- Redis queues and scheduler
- Docker production setup
- Spatie permissions
- React Query caching
- TypeScript frontend
- Professional enterprise UI

## 12. Close

FlowOps AI proves the ability to design, build, debug, and package a real full-stack business platform suitable for enterprise workflow use cases.
