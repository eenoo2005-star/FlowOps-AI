# FlowOps AI — Public Live Demo Plan

## Current Status

The project is currently documented as a local Docker portfolio build.

## Why Demo Credentials Are Not Public Yet

A demo email/password should not be published until the app is deployed to a public hosting environment with:

- Fake demo data
- Limited demo permissions
- No admin access
- No private company data
- Stable reset/reseed process

## Demo User Rules

The demo user should be able to:

- View dashboard
- Create sample requests
- View notifications
- View own request history

The demo user should not be able to:

- Delete production-like data
- Manage roles
- Manage permissions
- View private users
- Access admin-only settings
