# FlowOps AI — Recruiter One-Page

## Project

FlowOps AI — Enterprise Workflow / BPM / Operations Platform

## Role

Designed and built by Shaheen Idris as a full-stack software engineering portfolio project.

## What It Does

FlowOps AI helps organizations manage internal requests through departments, employees, request types, workflows, approvals, notifications, analytics, and enterprise administration.

## Why It Matters

Many companies still manage internal approvals through email, spreadsheets, and manual follow-up. FlowOps AI turns that into a structured workflow system with ownership, permissions, notifications, and operational visibility.

## Key Features

- Secure authentication
- Departments and employees
- Request type management
- Workflow builder
- Internal request creation
- Approval inbox
- Approve/reject engine
- Notification center
- Analytics dashboard
- Workspace search
- Enterprise administration
