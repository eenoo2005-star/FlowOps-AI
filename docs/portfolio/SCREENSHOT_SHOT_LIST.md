# FlowOps AI — Professional Screenshot Shot List

## Screenshot Rules

Use consistent browser size:

```text
1440 x 900
```

Recommended browser zoom:

```text
90% or 100%
```

Before taking screenshots:

- Press Ctrl + F5.
- Use clean demo data.
- Avoid messy random names.
- Use professional request type names.
- Hide browser bookmarks if they look unprofessional.
- Do not show private data or secrets.

## Naming Convention

Save screenshots into:

```text
docs/assets/screenshots
```

Use exactly these names:

```text
01-dashboard-light.png
02-dashboard-dark.png
03-departments-toast.png
04-create-request-dialog.png
05-approval-inbox.png
06-analytics.png
07-notifications.png
08-administration.png
09-audit-logs.png
10-workspace-search.png
```

## Required First Three

### 01-dashboard-light.png

Show the main dashboard in light mode.

### 04-create-request-dialog.png

Open Create Request and capture the request type/requester fields.

### 08-administration.png

Show role and permission administration.
