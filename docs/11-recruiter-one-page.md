# FlowOps AI — Recruiter One-Page

## Project

FlowOps AI — Enterprise Workflow / BPM / Operations Platform

## Summary

Built a production-style workflow management platform for internal company operations using Laravel, PostgreSQL, Redis, Docker, React, and TypeScript. The platform supports departments, employees, request types, workflow builder, internal requests, approval engine, approval inbox, notifications, analytics, search, security, and enterprise administration.

## Business Problem

Companies often manage internal approvals through email, spreadsheets, or disconnected systems. This causes delays, lack of visibility, weak auditability, and poor operational tracking.

## Solution

FlowOps AI centralizes request creation, workflow routing, approval tasks, notifications, analytics, and role-based administration in one platform.

## Key Features

- Authentication and protected routes
- Department and employee management
- Request type configuration
- Workflow builder
- Internal request lifecycle
- Approval task generation
- Approval inbox
- Approve / reject actions
- Notifications and notification bell
- SLA reminders and overdue escalation
- Analytics dashboard
- Workspace search
- Security page
- Enterprise administration
- Role and permission management
- Audit log browsing
- Dockerized runtime
- Health endpoint

## Stack

Frontend: React, TypeScript, Vite, Tailwind, React Query, React Router  
Backend: Laravel 12, PostgreSQL, Redis, Docker, queues, scheduler, Spatie Permission
